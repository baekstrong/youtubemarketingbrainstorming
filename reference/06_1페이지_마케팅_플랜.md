# 1페이지 마케팅 플랜 (브레인스토밍 활용 가이드)

> 이 문서는 1페이지 마케팅 플랜의 9단계 구조를 기반으로, 브레인스토밍 시 각 에이전트가 활용할 수 있도록 정리한 자료입니다.

---

## 1. 9단계 마케팅 플랜 구조

| 구분 | 단계 | 핵심 질문 |
|------|------|-----------|
| **사전 단계** (잠재 고객) | 1. 표적 고객 | 누구에게 팔 것인가? |
| | 2. 메시지 | 어떤 말로 설득할 것인가? |
| | 3. 매체 | 어디서 도달할 것인가? |
| **진행 단계** (관심 고객) | 4. 관심 고객 포착 | 어떻게 연락처를 확보할 것인가? |
| | 5. 관심 고객 육성 | 어떻게 신뢰를 쌓을 것인가? |
| | 6. 판매 전환 | 어떻게 결제하게 할 것인가? |
| **후속 단계** (진짜 고객) | 7. 최고의 경험 | 어떻게 만족시킬 것인가? |
| | 8. 고객생애가치 | 어떻게 더 오래 함께할 것인가? |
| | 9. 추천 시스템 | 어떻게 입소문을 낼 것인가? |

### 브레인스토밍 시 활용법
- **크리에이티브 디렉터**: 콘텐츠가 9단계 중 어디에 해당하는지 명확히 하고, 해당 단계의 목적에 맞는 방향 설정
- **스크립트 라이터**: 단계에 따라 톤과 CTA를 다르게 설계 (프론트엔드 콘텐츠 vs 백엔드 전환 콘텐츠)
- **커머스 매니저**: 단계별 자연스러운 전환 포인트 설계

## 2. 비즈니스 퍼널 (3단계)

| 단계 | 상품(Offer) | 타겟 고객의 상태 | 목적 |
|------|-------------|------------------|------|
| **프론트엔드** | 유튜브, 무료 PDF, 뉴스레터 | "체력은 기르고 싶은데 누군지 모름" | 인지도 상승 및 DB 확보 |
| **미들엔드** | 원데이 클래스, 종이책, 전자책 | "이 사람 말은 믿을만하네?" | 첫 결제 경험, 광고비 회수 |
| **백엔드** | 근력학교 정규반, 클래스101 | "이 사람에게 제대로 배우고 싶다" | 실질적 수익, 팬덤 형성 |

### 브레인스토밍 시 활용법
- 유튜브 콘텐츠는 **프론트엔드**임을 항상 인식할 것
- 영상의 CTA는 다음 단계(미들엔드)로의 전환을 유도해야 함
- 커머스 매니저는 각 영상이 어떤 미들엔드/백엔드 상품으로 연결되는지 설계

### 아바타에서 발견되는 공통 패턴

**공통 증상:**
- 계단 오르면 숨 참
- 아침에 일어나면 온몸 뻐근
- 오후 집중력 바닥
- 목/어깨/허리 만성 통증
- 주말에 밀린 잠만 잠

**공통 운동 실패 패턴:**
- 헬스장 등록 → 뭘 해야 할지 몰라 런닝머신만 → 한 달 내 포기
- 유튜브 홈트 → 영상 속 트레이너가 너무 잘함 → 자괴감 → 포기
- 버피/플랭크 시도 → 5-10개도 못함 → "나는 운동 체질이 아닌가봐"

**공통 심리적 장벽:**
- 운동하는 곳에서 내 체력이 드러나는 것이 창피
- 돈 내고 안 가면 돈 버림
- 이미 여러 번 실패해서 또 실패할 것 같음

**공통 니즈 키워드:**
- "하루 10-15분"
- "집에서, 장비 없이"
- "정말 기초의 기초"
- "나도 할 수 있겠다는 자신감"
- "다음 날 출근에 지장 없는 강도"

### 브레인스토밍 시 활용법
- **크리에이티브 디렉터**: 아이디어 제안 시 "이 콘텐츠가 어떤 아바타를 타겟하는가?" 명시
- **스크립트 라이터**: 해당 아바타의 언어/증상/상황을 후크와 공감 파트에 직접 활용
- **커뮤니티 매니저**: 아바타의 심리적 장벽을 기반으로 댓글 반응 예측
- **비주얼 디자이너**: 아바타의 일상 장면을 썸네일/영상 비주얼에 반영

## 4. 독특한 판매 제안 (USP) 상세

### USP 9가지 축

| # | USP | 설명 |
|---|-----|------|
| 1 | 직장인 출신 코치 | 사무직 경험자가 직접 가르침 → 고객 맥락 이해 |
| 2 | 생존 체력 전문 | 살빼기 X, 몸만들기 X → 체력 향상만 집중 |
| 3 | 지속 가능한 강도 | 빡세지 않지만 효과적 → 다음날 출근 가능 |
| 4 | 에너지 버퍼 설계 | 오후 4시 방전 방지 → 일상을 지켜주는 운동 |
| 5 | 시성비(시간 대비 성능) | 가성비가 아닌 시간 효율 중심 → 주 2-3회 |
| 6 | 심리적 문턱 파괴 | 시작의 두려움을 제거하는 시스템 |
| 7 | 데이터 기반 체력 성적표 | 체력 변화를 수치로 확인 (웹앱 연동 예정) |
| 8 | 체력 커뮤니티 | 비슷한 체력 수준끼리 모임 (개발 예정) |
| 9 | 성과 중심 컨설팅 | 대기업 출신의 결과 지향적 접근 |

### 거부할 수 없는 제안
> "우리는 단순히 운동을 시키는 곳이 아닙니다. 직장인 출신 코치가 직접 설계한 '생존 체력 프로그램'과 '전용 앱'을 통해, 당신의 퇴근 후 일상을 완전히 바꿔놓는 '에너지 솔루션'을 제공합니다."

### 제안서 필수 요소
| 요소 | 내용 |
|------|------|
| 가치 | 저질 체력 → 강철 체력, 일을 더 잘 할 수 있는 상태 |
| 이유 | 불만족시 100% 환불 (2-3주 수업 후에도 가능) |
| 희소성 | 한 달에 딱 4명만 신규 등록, 저녁 시간 자리 제한 |
| 보증 | 체험 수업이 없는 대신 100% 환불 보장 |

### 브레인스토밍 시 활용법
- **스크립트 라이터**: USP를 영상 내 자연스럽게 녹여내되, "광고 느낌"이 나지 않도록 설계
- **커머스 매니저**: 희소성/보증 요소를 CTA에 활용
- **크리에이티브 디렉터**: 콘텐츠가 USP 중 어느 축을 강화하는지 체크

## 5. 본능 분석 & 반박 제거

> 잠재 고객이 행동하지 않는 진짜 이유 10가지와, 콘텐츠에서 어떻게 해소할 것인지

### 두려움 → 해소 메시지 매핑

| # | 두려움 | 해소 메시지 | 콘텐츠 활용 |
|---|--------|-------------|-------------|
| 1 | 시간 부족 | "주 2회 1시간. 출근 전 7시 / 퇴근 후 7시 중 선택" | 시간 효율 강조 영상 |
| 2 | 체력 노출 창피 | "8년간 2,000명의 체력 바닥 직장인과 시작" | 공감 기반 스토리 |
| 3 | 또 작심삼일 | "3개월 출석률 평균 92%" | 데이터 기반 신뢰 구축 |
| 4 | 더 다칠까봐 | "직장인 출신 트레이너가 직접 봅니다" | 안전성 강조 콘텐츠 |
| 5 | 돈 낭비 | "첫 달 4회 체험 후 결정" | 진입 장벽 낮추기 |
| 6 | 강도 부담 | "다음날 출근 가능한 강도. 근육통 ≠ 효과" | 운동 상식 깨기 시리즈 |
| 7 | 비교 열등감 | "5명 소그룹, 비슷한 체력끼리 매칭" | 커뮤니티 안전감 |
| 8 | 효과 없을 것 | "12주 후 계단 숨참 50% 감소 (실측 데이터)" | Before/After 콘텐츠 |
| 9 | 루틴 변화 부담 | "출퇴근 동선 위 위치. 운동복 보관 무료" | 접근성 강조 |
| 10 | 완벽주의 | "70% 동작만 해도 됨. 8년간 큰 부상 0건" | 완벽주의 해소 콘텐츠 |

### 추천 핵심 메시지 (추상적 표현 대체)
- ❌ "최소한의 시간으로 최대한의 체력 향상"
- ✅ "주 2회 1시간, 3개월이면 계단에서 안 헉헉댑니다"
- ✅ "허리 아픈 직장인도 안전하게, 다음날 출근 가능한 강도"
- ✅ "체력 바닥인 사람만 8년간 2,000명 트레이닝했습니다"

### 브레인스토밍 시 활용법
- **스크립트 라이터**: 영상 도입부(공감 파트)에서 두려움을 직접 언급하고, 본문에서 해소 메시지 전달
- **커뮤니티 매니저**: 댓글에서 나타나는 두려움 패턴을 매핑하여 다음 콘텐츠 제안
- **크리에이티브 디렉터**: 추상적 메시지를 구체적 메시지로 변환하는 기준으로 활용

## 6. 공공의 적 (3단계)

> 잠재 고객과 "같은 편"이 되기 위해, 함께 싸울 적을 정의

### 1차 공공의 적 (직접적 원인)
- 장시간 앉아있는 업무 환경
- 회식/야근 문화
- 퇴근 후 남는 시간/에너지 부족
- 불규칙한 식사 시간과 회사 근처 식당들

### 2차 공공의 적 (심리적 장벽 = 잘못된 고정관념)
- "운동 = 헬스장 = 비싸고 멀다"
- "PT 받아야 제대로 배운다"
- "시간 많이 투자해야 효과 있다"
- 운동하다 다친 경험/주변 사례

### 3차 공공의 적 (사회적 압박)
- "회사에서 운동하면 한가한 사람" 시선
- "30대 남자가 그것도 못해?"라는 자괴감
- SNS 운동 고수들과의 비교
- "일도 못하는데 무슨 운동"이라는 자기검열

### 근력학교가 콘텐츠에서 강조할 공공의 적
1. **회사가 만든 망가진 몸** (허리, 어깨, 무릎)
2. **"운동할 시간 없다"는 핑계를 정당화하는 회사 문화**
3. **잘못된 운동 상식** (많이 해야 효과 있다, 매일 해야 한다 등)

### 브레인스토밍 시 활용법
- **스크립트 라이터**: "공공의 적" 프레이밍으로 시청자와 같은 편이 되는 후크 설계
- **크리에이티브 디렉터**: 공공의 적을 공격하는 콘텐츠 시리즈 기획 가능
- **커뮤니티 매니저**: 시청자가 공감할 수 있는 "적" 서사를 콘텐츠에 반영

## 7. 직장인 회사 생활 고통 10가지

> 콘텐츠 후크, 썸네일 카피, 공감 파트에 직접 활용할 수 있는 구체적 장면들

| # | 고통 | 활용 가능 후크 예시 |
|---|------|---------------------|
| 1 | 아침 출근길부터 이미 지침 | "출근만 했는데 이미 한 일 다 한 기분?" |
| 2 | 오전 회의에서 이미 졸림 | "10시 회의에서 고개 떨구는 거 들킬까 긴장되시죠" |
| 3 | 점심 먹고 완전 셧다운 | "화장실 칸에서 5분이라도 눈 붙이고 싶은 적?" |
| 4 | 오후 3-4시 집중력 바닥 | "메일 한 통 쓰는 데 30분 걸리기 시작하면" |

## 9. 콘텐츠 기획 시 체크리스트 (마케팅 플랜 기반)

브레인스토밍 Phase 4(심화 작업) 또는 Phase 5(최종 확인) 시 아래 항목을 점검:

### 퍼널 정합성 체크
- [ ] 이 콘텐츠는 퍼널의 어느 단계인가? (프론트/미들/백)
- [ ] 다음 단계로의 전환 포인트가 설계되어 있는가?
- [ ] CTA가 해당 단계에 적합한가?

### 타겟 정합성 체크
- [ ] 주요 타겟 아바타 1-2명을 지정했는가?
- [ ] 해당 아바타의 구체적 증상/상황이 콘텐츠에 반영되어 있는가?
- [ ] 해당 아바타의 심리적 장벽을 해소하는 내용이 있는가?

### 메시지 정합성 체크
- [ ] USP 9가지 중 어느 축을 강화하는 콘텐츠인가?
- [ ] 추상적 표현 대신 구체적 수치/장면이 사용되었는가?
- [ ] "공공의 적" 프레이밍이 자연스럽게 녹아있는가?

### 반박 제거 체크
- [ ] 시청자가 느낄 수 있는 두려움/반박을 예상했는가?
- [ ] 해당 두려움에 대한 해소 메시지가 콘텐츠에 포함되어 있는가?
- [ ] 구체적 데이터/사례로 뒷받침하고 있는가?
